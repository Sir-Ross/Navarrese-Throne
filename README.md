# Navarrese-Throne
An alternate history mod for Victoria II where the French throne is inherited by Navarra during the Hundred Years War.
The original timeline for this mod can be found here: https://althistory.fandom.com/wiki/Navarrese_Throne

## Flags
The flags of each tag can be seen below. They are ordered default, republic, monarchy, fascist, then communist.
